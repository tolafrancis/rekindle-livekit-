# packages/

order (least-dependent first): `types` → `supabase` → `auth` → `live` → `ui` → `features`.

Empty at Phase 0. Each package is added one PR at a time per the extraction map:
[docs/investigations/phase1-extraction-map.md](../docs/investigations/phase1-extraction-map.md).
